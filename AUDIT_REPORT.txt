 F. NEW FEATURES / ENHANCEMENTS SUGGESTED
================================================================================

F1. [NEW] Dark Mode / Theme Toggle
    App is light-only. Add dark mode toggle in Settings or header bar.
    globals.css already has CSS variables that could support theming.

F2. [NEW] Real-time notifications panel
    Add a bell icon in header with dropdown showing recent activities:
    new jobs, payments received, low stock alerts, bay completions.

F3. [NEW] Service History Timeline per Vehicle
    In Vehicles page, show a visual timeline of all services performed
    on each vehicle with dates, costs, and mechanic info.

F4. [NEW] Automated Service Reminders
    Based on last service date + configurable interval (e.g., 90 days),
    auto-flag vehicles due for service. Show on Dashboard and CRM.

F5. [NEW] Customer Communication Log
    WhatsApp/SMS message history per customer. Track sent invoices,
    reminders, and promotional messages.

F6. [NEW] Multi-user Role-Based Access (RBAC)
    Currently single-user "Admin Owner". Add roles: Admin, Receptionist,
    Mechanic, Accountant — each with different page access permissions.

F7. [NEW] Expense Tracker
    Track shop expenses (rent, utilities, parts purchases, salaries).
    Feed into Accounting page for real profit/loss calculations.

F8. [NEW] Job Card Status Workflow Automation
    Auto-advance status: PENDING → IN_PROGRESS (on bay assign) →
    COMPLETED (on mechanic mark-done) → DELIVERED (on payment).

F9. [NEW] Vehicle Photo Gallery
    Allow uploading before/after photos per job card for documentation
    and customer communication.

F10. [NEW] Search Across All Modules (Global Search)
     Add a universal search bar in header that searches across customers,
     vehicles, jobs, invoices, and inventory simultaneously.

F11. [NEW] PDF Invoice Download
     Currently only print preview. Add "Download PDF" button using
     jsPDF or html2canvas for offline invoice sharing.

F12. [NEW] Mechanic Workload Balancing View
     Visual dashboard showing each mechanic's current load, queue depth,
     and estimated availability for new assignments.

F13. [NEW] Parts Low-Stock Auto Reorder Suggestions
     When parts hit minimum threshold, auto-suggest reorder quantities
     based on historical consumption patterns.

F14. [NEW] Customer Loyalty / Rewards Points System
     Track customer visits and spending. Offer service discounts after
     X visits or Y amount spent.

F15. [NEW] Dashboard — Connect charts to real data
     Replace static demo arrays with computed values from actual
     job cards, invoices, inventory, and mechanics data.
